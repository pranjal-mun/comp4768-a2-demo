# COMP4768 Assignment 2: Adopt & Foster (demo)

A working build of Assignment 2, so you can see how the app is supposed to behave.

Open it here: https://pranjal-mun.github.io/comp4768-a2-demo/animals

Try the URLs from the assignment, for example `/animals?species=cat&need=foster`, `/animals/3` and `/animals/42`.
Applications are kept in memory only, so they disappear when you reload the page.

This repository holds only the compiled web app. It is not the source code.
